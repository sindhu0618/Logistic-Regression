# Logistic Regression

A machine learning project implementing **Logistic Regression** using Python to predict student outcomes.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Jupyter Notebook

## Project Steps

1. Load the dataset
2. Handle missing values
3. Perform data preprocessing
4. Explore the dataset
5. Split the data into training and testing sets
6. Train the Logistic Regression model
7. Make predictions
8. Evaluate the model

**Logistic Regression**
